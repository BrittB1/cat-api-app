## 1️⃣ Push your latest work
 
Make sure everything is committed and **pushed to `dev`**.
👉 If it's only on your laptop, it won't be in the PR!
 
## 2️⃣ Go to the repo on GitHub
 
Open the **cat-api-app** repo.
✨ See a yellow **"Compare & pull request"** banner? Click it and skip to step 4!
 
## 3️⃣ Start the pull request
 
Click the **Pull requests** tab, then the green **New pull request** button. 🟢
 
## 4️⃣ Set the direction ⚠️ (most important step!)
 
Two dropdowns will appear. Set them like this:
 
- 🎯 **base:** `main`
- 🌱 **compare:** `dev`
This means *"pull the changes FROM `dev` INTO `main`."*
🔁 Getting these backwards is the #1 mistake — double-check **base is `main`**!
 
## 5️⃣ Peek at the changes 👀
 
GitHub shows everything about to be merged. Scroll through and make sure it looks right.
 
## 6️⃣ Create + merge 🎉
 
- Click **Create pull request**
- Add a short **title** (like "Add Router and page navigation")
- Click **Merge pull request** ➡️ **Confirm merge**
## 7️⃣ Sync your local `main` (don't forget! 🧠)
 
The merge happened up on GitHub, so your laptop is behind. In **VS Code**:
 
- 🔽 Click the branch name (**bottom-left corner**) → switch to **`main`**
- 🔄 Click the **sync icon** (circular arrows, bottom-left) to pull it down
- 🔼 Click the branch name again → switch back to **`dev`**
🏡 **Always end up back on `dev`** so your next work goes to the right branch!

## 🌟 Quick Recap
 
| Step | What to do |
|------|-----------|
| 1 | Push everything to `dev` |

Happy merging! 🐱💗
